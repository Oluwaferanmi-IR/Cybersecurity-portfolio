# pfSense Network Security Lab

## Overview
pfSense is an open-source firewall and router software used to secure, manage, and monitor networks. It is based on FreeBSD and is commonly installed on a dedicated computer or virtual machine.
This project was done to demonstrate the deployment, configuration, and monitoring of a pfSense firewall in a virtual lab. The lab simulates real-world attack scenarios and applies defensive security controls commonly used in enterprise networks.

## Objectives
- Deploy pfSense as a perimeter firewall
- Design a segmented network (WAN and LAN)
- Implement firewall rules 
- Simulate external attacks using Kali Linux
- Detect malicious activity using Suricata IDS/IPS
- Analyze logs 

## Lab Architecture
- pfSense (Firewall & Router)
- Kali Linux (Attacker)
- Metasploitable / DVWA (Vulnerable internal host)
- Internal Client (Legitimate user)

## Tools & Technologies
- pfSense
- Suricata IDS/IPS
- Kali Linux
- Nmap
- VMware
- SIEM
