## WINDOWS 2019 SERVER SETUP


## OVERVIEW
This project demonstrates the setup and configuration of a Windows Server in VMWARE, setting up Active Directory environment, including Organizational Units (OU) and user account management.

## SETUP PROCES

1. Download the .iso file for the window server
2. Open vmware (the virtual machine we I used for the purpose of this lab)
3. click 'file"
4. click 'new virtual machine'
5. click 'typical (recommended)" and 'next"
6. clicn "i will install the operanting system later" and click next
7. In guest OS, choose "Microsoft windows". In Version, choose "windows server 2019"
8. Follow the remaining prompt till finish
9. In vmware, click on the server
10. Go to settings
11. go to CD/DVD (SATA)
12. Click on 'use ISO image file"
13. Browse the .iso file downloaded earlien=r and click ok
14. Power on thw virtual machine

15. click next
16. Click install
17. choose 'windows server 2019 Datacenter Evaluation Desktop Experience' and click next

19. click on "custom: install windows only'
20. click next
21. the installation would begin
